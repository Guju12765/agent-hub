## Feature List
1. Agent Configuration - define and configure AI agents
2. MCP Server - Model Context Protocol server implementation
3. Memory System - persistent memory with vector embeddings
4. CLI Interface - command-line tools for agent management
5. Storage Layer - SQLite-based data persistence
6. Template System - agent templates and scaffolding

- Agents: Configured via YAML/JSON definitions
- Memory: SQLite with sqlite-vec for vector search
- MCP: Follows Model Context Protocol specification
- CLI: Subcommand-based interface
